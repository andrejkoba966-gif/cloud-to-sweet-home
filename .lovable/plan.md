# Подключение проекта к GitHub (Git sync)

## Цель
Настроить двустороннюю синхронизацию кода Lovable-проекта с GitHub-репозиторием, чтобы изменения в Lovable автоматически пушились в GitHub, а правки в GitHub синхронизировались обратно.

## Текущее состояние
Проект не подключён к GitHub (в `.lovable/project.json` нет данных о репозитории).

## Что будем делать
1. Открыть в Lovable редактор проекта.
2. Через меню «+» (Plus) в чате выбрать **GitHub → Connect project**.
3. Авторизовать Lovable GitHub App в нужном GitHub-аккаунте.
4. Выбрать аккаунт или организацию, куда создавать репозиторий.
5. Создать репозиторий через Lovable — в него загрузится текущий код проекта.
6. Убедиться, что синхронизация работает: изменения в Lovable появляются в GitHub, а коммиты/PR из GitHub подтягиваются в Lovable.

## Ограничения и важные моменты
- Lovable не импортирует существующий GitHub-репозиторий — создаётся новый репозиторий из проекта.
- Секреты и переменные окружения (например, токены Telegram, API-ключи) в GitHub не переносятся — их нужно будет прописать вручную, если планируешь деплой вне Lovable.
- Доступен выбор веток и работа через pull requests прямо из редактора.

## Результат
Репозиторий на GitHub с актуальным кодом сайта AD Simple и включённой двусторонней синхронизацией.
